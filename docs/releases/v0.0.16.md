# PAI v0.0.16

发布日期：2026-06-16

## 修复与优化

- **修复更新下载进度弹窗重复创建问题**：在更新下载过程中，进度条弹窗（Modal）之前每次 `progress` 变化时都会销毁并重新创建，导致弹窗频繁闪烁、用户体验不佳。本次改用 `useRef` 持久化弹窗实例，通过 `modalRef.current.update({ content })` 更新内容，避免重复销毁重建，弹窗过渡更平滑。

## 技术与兼容性说明

- 修改范围：仅 `frontend/src/composables/useUpdater.tsx` 一个文件。
- 不影响后端、打包流程、数据存储或其他模块。
