# PAI v0.0.17

发布日期：2026-06-26

## 更新亮点

- 支持在同步记录列表中快速复制现有同步配置，适用于基于同一配置创建“近似配置”场景。

## 主要变更

- 新增「复制」操作入口：同步记录卡片新增复制按钮，可直接基于已有记录打开配置弹窗。
- 复制模式复用编辑表单并预填配置：名称默认追加“（副本）”后缀，源路径、目标路径、分支信息会自动填充。
- 优化弹窗标题与行为区分：新增复制/编辑/新建三种弹窗模式，避免不同操作下按钮与标题语义混淆。

## 技术与兼容性说明

- 修改范围仅覆盖 `frontend/src/views/SyncView.tsx`。
- 行为为前端交互增强，不涉及数据库结构、后端接口、发布脚本或打包流程变更；对现有配置读取与执行逻辑影响较小，但建议对新旧同步记录的新增与复制场景进行验证。

## 下载说明

请在本 Release 的 Assets 中下载 Windows 安装包或可执行文件。
